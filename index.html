Capabilities

Everything you need to study the overlay layer

Six focused modules, each one isolated and toggleable so you can benchmark detection behaviour module by module.

🦴

Player Skeleton ESP

Bone-accurate skeleton draw from the actor's component transform chain, with optional bounding boxes and distance scaling.

✨

Item Glow

Highlights loot, weapons and attachments through a colour-coded glow pass — useful for studying world-entity enumeration.

🎯

No-Recoil Analysis

Visualises the recoil impulse curve per weapon so you can inspect how the engine applies spread and kick over time.

🗺️

Live Radar

A top-down minimap fed by read-only memory snapshots — shows player bearings, distance rings and zone boundaries.

🔌

DMA Read-Only Mode

All reads go through an external DMA card. Nothing is written back to the target process, keeping the surface minimal.

🧪

Detection Lab

Built-in logging of signature checks and heuristic probes encountered during a session, exported as JSON for research.

How it works

From download to overlay in three steps

No kernel driver installs, no game-file patching — the flow stays entirely outside the target process.

1

Download & verify

Grab the latest build from the release page, extract the archive and check the SHA-256 hash against the published checksum before running anything.

2

Attach the DMA device

Connect your external DMA card, launch the overlay loader and select the target process. The tool confirms read-only access before any module loads.

3

Toggle modules & observe

Enable skeleton ESP, item glow, radar or the recoil analyser from the overlay panel. Logs stream live so you can study each detection event as it happens.
